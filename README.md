# Pentimento

A steganalysis corpus of 10,000 permissively licensed cover photographs and
matched stego pairs, where every image carries its own licence.

Built by [Stegobench](https://github.com/elementmerc/stegobench), which is the
harness. This repository is the corpus: its documentation, its release
metadata, and the record of how it was made.

The images themselves are not here. They are published to the Internet
Archive, HuggingFace, Kaggle and Academic Torrents, because 48 GB does not
belong in git.
